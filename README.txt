TURNROWS REFERRAL CENTER — VERSION 2

This is a mobile-friendly referral management web app.

Current features:
- Dashboard
- Partner database
- Referral entry/editing
- $50 reward tracking
- Unique partner referral links
- QR code display/download via QuickChart
- Local browser storage
- JSON backup/export
- Seeded with initial Turnrows prospects

Important:
This prototype stores data in the browser's localStorage. It is excellent for testing the workflow, but it is NOT yet a multi-user cloud database.

Recommended production upgrade:
- Supabase or Airtable as shared database
- User authentication
- Staff roles
- Partner portal
- Automated email notifications
- Amazon gift-card fulfillment
- Unique QR codes on partner cards
- Duplicate referral detection
- Audit log

To run:
Open index.html in a browser. For phone testing, upload the folder to a static host such as Netlify, Vercel, or Cloudflare Pages.
